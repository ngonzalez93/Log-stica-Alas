Actualizar base de clientes

Cargá un archivo Excel o CSV para agregar coordenadas faltantes, corregir datos o sumar clientes nuevos. La combinación se hace por código de cliente.

Arrastrá tu archivo aquí o hacé clic Formatos: .xlsx, .xls, .csv
Columnas esperadas (los nombres pueden variar):
  1. Cod_Cliente — obligatorio, identifica al cliente.
  2. Latitud y Longitud — para geolocalizar.
  3. Opcionales: Nom_Cliente, Depart_Cliente, Ciudad_Cliente, Vend_Asignado.
Consejo: usá «Descargar plantilla» para obtener los clientes sin ubicación listos para completar.
